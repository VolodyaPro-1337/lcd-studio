# LCD Studio

Программа для вывода чего угодно на LCD-экран корпуса ПК (делалась под DEXP GS Ravager, 11.8").
Устроена как OBS: сцены из слоёв, которые можно двигать, масштабировать и поворачивать мышью.

## Что умеет

**Слои:**
- рабочий стол целиком или область, окно отдельной программы (даже перекрытое);
- картинки и GIF, видео, слайд-шоу из папки;
- текст и бегущая строка, в тексте можно подставлять значения датчиков (`CPU {auto/cpu_temp}`);
- часы в любом формате, цвет или градиент;
- датчик в одном из 7 видов (кольцо, спидометр, полоса, столбик, график, число, текст);
- панель мониторинга из своего набора плиток, топ процессов.

**Редактор:**
- прилипание к краям и центру, отмена и повтор;
- порядок, видимость и закрепление слоёв;
- несколько сцен с автопереключением;
- перетаскивание файлов прямо на холст.

**Мониторинг:**
- psutil, LibreHardwareMonitor и nvidia-smi;
- «умные» датчики `auto/*`, которые сами находят сенсор на любом железе;
- пинг до любого адреса.

**Прочее:** работает из трея, автозапуск (с правами администратора — через планировщик задач), запускается только одна копия.

## Запуск из исходников

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python tools\fetch_lhm.py      # LibreHardwareMonitorLib + зависимости из NuGet
.venv\Scripts\pythonw run.pyw
```

Нужны Windows 10/11 x64, Python 3.14 и .NET Framework 4.7.2+ (для LibreHardwareMonitor).
Температура CPU и датчики материнской платы доступны только при запуске от имени администратора,
на части платформ нужен ещё драйвер [PawnIO](https://pawnio.eu).

## Сборка exe

```powershell
powershell -File build.ps1               # -> dist\LCD Studio\LCD Studio.exe
powershell -File build.ps1 -Dist dist_new  # если старая копия запущена и держит dist
```

Папку `dist\LCD Studio` можно заархивировать и отдать: Python и прочее ставить не нужно.

## Устройство

| Файл | Что внутри |
|---|---|
| `lcdstudio/app.py` | главное окно: сцены, слои, свойства, настройки экрана, трей |
| `lcdstudio/editor.py` | холст-редактор и `render_scene` — сборка кадра из слоёв |
| `lcdstudio/model.py` | типы слоёв и их свойства по умолчанию |
| `lcdstudio/sources.py` | источники: экран, окно, картинка, видео, текст, часы... |
| `lcdstudio/monitor.py` | виджеты датчиков, панель, процессы, подстановка `{датчик}` в текст |
| `lcdstudio/sensors.py` | сбор датчиков в фоне (`hub`) |
| `lcdstudio/props.py` | редакторы свойств слоёв |
| `lcdstudio/outputs.py` | вывод: окно на мониторе и интерфейс USB-драйвера экрана |

Настройки хранятся в `%APPDATA%\LcdStudio\config.json`; переменная окружения `LCDSTUDIO_CONFIG`
задаёт другой файл.

## Драйвер USB-экрана

Пока экран можно использовать, только если Windows видит его как монитор (вкладка «Экран корпуса» →
«Выводить окном на монитор»). Для USB-экрана со своим контроллером нужно реализовать класс в
`lcdstudio/outputs.py` и добавить его в `DEVICES`:

```python
class MyLcd(Device):
    name = "DEXP GS Ravager (USB)"

    def open(self) -> bool:      # найти устройство по VID/PID, вернуть True при успехе
        ...

    def send(self, img: QImage):  # кадр уже в разрешении и повороте экрана
        ...

    def close(self):
        ...

DEVICES.append(MyLcd)
```

После этого экран появится в выпадающем списке «USB-экран», и каждый кадр будет уходить в `send()`.
